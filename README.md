# BearCut 🐻✂️

**自動順剪：把毛片剪成可用的成片，並自己檢查剪得對不對。**

錄了一小時，一半是重講、吃螺絲、「呃…」跟長長的空白。BearCut 讀懂你在講什麼，
把講壞的部分剪掉，接成一支順的片子 —— 然後**再回頭驗證自己剪得對不對**。

> ✅ **v0.1 可用**：核心順剪、字幕、網頁介面、AI Agent 驅動都已完成。
> 短影音視覺處理（大字卡、直式排版）在下一版，見 [開發進度](#開發進度)。

---

## 這跟其他自動剪輯工具差在哪

| | 一般工具 | BearCut |
|---|---|---|
| 剪什麼 | 靜音、無聲片段 | 靜音 **＋ 重講、NG take、吃螺絲、卡頓** |
| 怎麼決定 | 音量門檻 | 讀逐字稿**理解語意**，再由字級時間戳定位切點 |
| 剪完呢 | 交給你 | **自己回測**：模擬接縫、重新辨識成片、音畫字同步檢查 |
| 誰來操作 | 你 | 你，**或你的 AI Agent** |

核心設計原則：**語意判斷與時間戳職責分離。** AI 只決定「剪什麼內容」，
每一刀的實際秒數一律由字級時間戳反查 —— 因為語言模型報的時間不能信。

## 安裝

### 一般使用者：雙擊就好

**Windows** — 雙擊 `START_HERE.bat`

它會自己檢查 Python、建虛擬環境、裝套件、下載 FFmpeg，然後開起來。
**全程不需要開終端機，也不會動到你的系統設定** —— 所有東西都裝在這個資料夾裡。

macOS 想先試的話是 `START_HERE.command`（首次需右鍵 → 開啟），但請有心理準備會遇到問題。

### 開發者

```bash
python bootstrap.py      # 建 venv + 裝套件 + 抓 ffmpeg
python cli.py doctor     # 檢查環境
```

## 🤖 給 AI Agent

**如果你是 AI Agent（Claude Code、Codex、Cursor…），照這個流程做：**

```bash
# 1. 先看環境缺什麼。所有指令都支援 --json，輸出可直接解析。
python cli.py doctor --json
```

讀回傳 JSON 的 `ok` 欄位：

- **`ok: true`** → 環境就緒，可以往下做事
- **`ok: false`** → 看 `blocking` 陣列知道缺哪幾項，然後執行：

```bash
python bootstrap.py      # 會把缺的補齊；每一項失敗都會回傳可讀的中文原因
```

補充說明：

- `checks.<項目>.fix` 欄位直接寫了每一項該怎麼修，可以照著做
- `platform.gpu.kind` 是 `cuda` / `mps` / `cpu`，決定辨識速度
- `llm.ok` 為 false 時只會降級（僅剪靜音），不會整個失敗。
  **注意：你是操作者，不是判斷腦**——BearCut 要在剪片途中自己呼叫判斷腦幾十輪，
  所以機器上仍需一顆 CLI 或 API 金鑰。`checks.llm.fix_command` 是可直接執行的安裝指令
- **不需要修改任何系統設定或環境變數**，也不需要 sudo / 系統管理員權限
- ffmpeg 會下載到 `vendor/`，不會裝到系統上

## 怎麼用

**網頁介面**（推薦）—— 雙擊 `START_HERE`，瀏覽器會自動打開。
拖影片進去 → 選「效率／平衡／精準」→ 按一顆按鈕。

**指令列**
```bash
python cli.py cut 影片.mov                  # 平衡模式（預設）
python cli.py cut 影片.mov --mode fast      # 快 2-3 倍、token 約 1/3
python cli.py cut 影片.mov --mode precise   # 不計成本求準
python cli.py cut 影片.mov --plan-only      # 只產清單給人複核，先不剪
python cli.py cut --apply 待剪清單.json      # 改過清單後重剪（不必重跑辨識）
```

### 產出

| 檔案 | 用途 |
|---|---|
| `_淨毛片.mp4` | 剪好的成片 |
| `_字幕校對_V1.txt` | 純文字逐字稿，給人讀與改 |
| `_字幕.srt` | 給剪輯軟體與平台 |
| `_剪輯判斷對照.txt` | **逐刀說明剪了什麼、為什麼** |
| `_待剪清單.json` | 可以改，改完用 `--apply` 重剪 |

不同意某一刀？打開對照表看原因，改清單重剪就好 —— 不必重跑辨識。

## 做短影音

剪好之後，一行變成可以直接發的直式短片：

```bash
python cli.py shortform 淨毛片.mp4 --title "開場標題" --cta "留言告訴我"
```

自動加上字幕、關鍵詞上色、大字卡、封面，全部避開平台 UI 的安全框。

- `--follow` 追講者裁切（**單人時才用**，雙人對談會漏人）
- `--no-cards` 不做大字卡　`--no-cover` 不做封面

## 檢查品質

```bash
python cli.py verify 成片.mp4 --frames
```

檢查音畫字同步、字幕品質，並在**每個刀口前後抽幀**讓你確認接得順不順。

## 更新規則

剪輯的手感會一直進步。規則（門檻、判斷詞、字卡樣式）可以單獨更新，不必重裝程式：

```bash
python cli.py update              # 更新到最新規則
python cli.py update --check-only # 只看有沒有新版
python cli.py update --rollback   # 不滿意就還原
```

免費版走 GitHub Releases 拿基礎規則包，不必登入。
有 [Pro](#bearcut-pro) 授權碼的話先 `python cli.py login <授權碼>`，之後 `update` 就會拿 Pro 規則包。

每個規則包都附 SHA-256，下載後一定比對；對不上就整包丟掉、保留你原本的規則包，
不會拿一份來路不明的規則去改你的剪輯結果。

## 系統需求

- **Windows 10 / 11**（其他平台見上方「平台支援」）
- **Python 3.9 以上**（安裝器會檢查，沒有會引導你裝）
- 硬碟空間約 5 GB（模型與 FFmpeg）
- GPU 選用：有 NVIDIA 顯卡會自動加速，沒有也能跑（CPU 較慢但可用）

判斷腦（擇一即可，沒有則只剪靜音）：
- 本機 CLI：`claude`、`codex`、`gemini` —— **免金鑰**，用你現有的付費方案登入即可
  - Windows：`irm https://claude.ai/install.ps1 | iex`
  - macOS / Linux：`curl -fsSL https://claude.ai/install.sh | bash`
- 或 API 金鑰：`ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `GEMINI_API_KEY`

> **用 Claude Cowork 之類的 AI agent 操作 BearCut 的人請注意**：那個 agent 是**操作者**，
> 不是判斷腦。剪片途中 BearCut 要自己呼叫判斷腦幾十輪，不能停下來等 agent 回話，
> 所以同一台機器上仍要裝一顆 CLI（或給金鑰）。裝完之後你照樣用 agent 操作，
> 那顆 CLI 只是躺在硬碟上被背景呼叫，你不會看到它。
