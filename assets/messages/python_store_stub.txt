  你的電腦上有 Python 的「捷徑」，但沒有真的裝 Python。

  Windows 內建了一個指向微軟市集的空捷徑，看起來像裝好了，
  實際執行卻只會跳出市集視窗，所以剛才什麼訊息都沒有出現。

  請照以下步驟做，大約三分鐘：
    1. 按 Enter 會自動開啟 Python 官方下載頁
    2. 下載並執行安裝檔（選 Windows installer 64-bit）
    3. 安裝時務必勾選「Add python.exe to PATH」
    4. 裝完後回來重新雙擊 START_HERE

  如果裝完還是出現這個訊息，請到
  「設定 → 應用程式 → 進階應用程式設定 → 應用程式執行別名」
  把 python.exe 與 py.exe 這兩項關掉，再試一次。
