# 做直式短影音

## 前提

要先有**剪好的影片與字幕**。如果使用者給的是原始毛片，先走 **bearcut-cut**。

## 執行

```bash
python cli.py shortform "<影片>" --title "開場標題" --cta "留言告訴我" --json
```

會自動找同名的 `_字幕.srt`。找不到就只有畫面沒有字幕，要提醒使用者。

### 參數怎麼給

| 使用者說 | 加什麼 |
|---|---|
| 沒特別說 | 不用加，預設會挑金句做字卡 + 產封面 |
| 「不要字卡」「太花了」 | `--no-cards` |
| 「只有我一個人入鏡」 | `--follow`（會裁到講者、滿版） |
| 「兩個人對談」 | **不要**加 `--follow`（會漏人） |
| 「不用封面」 | `--no-cover` |

**標題與 CTA 要問使用者，不要自己編。** 那是他的內容與品牌語氣。
如果他沒給，可以從逐字稿提兩三個建議讓他挑。

## 產出

- `_直式.mp4` — 9:16 成片，含字幕、關鍵詞上色、大字卡
- `_封面.jpg` — 三帶標題封面
- `_直式.ass` — 字幕樣式檔（要微調可以直接改這個再重燒）

## 版面知識（回答使用者問題時用）

- **字卡放上方**：臉在中央，壓上去會遮表情，而表情是說服力的一部分
- **不裁切前景**：雙人對談裁了會漏人，所以預設用模糊填底
- **安全框**：所有元素都避開平台 UI（頂 115px、底 1575px、右側互動欄從 y≥1090 起）
- **關鍵詞每句最多 1-2 個**：整句都上色等於都沒上色

## 注意

- 轉直式要重新編碼，**一支 90 秒的片約 40 秒–2 分鐘**，不要設短逾時。
- 「來源為直式，直接填滿」是正常訊息，代表偵測到手機直拍、省掉了不必要的合成。
