# 用 BearCut 順剪影片

## 開始前

先確認環境（很快，值得做）：

```bash
python cli.py doctor --json
```

`ok` 不是 `true` 就先走 **bearcut-setup**。

## 挑模式

使用者的說法決定用哪個模式，**不要問他 model_size 這種問題**：

| 使用者說 | 用 |
|---|---|
| 「快一點」「先看個大概」「素材很多」「試試看」 | `--mode fast` |
| 沒特別說 | 預設（balanced），不用加參數 |
| 「要準」「交件用」「重要」「仔細一點」 | `--mode precise` |

## 執行

```bash
python cli.py cut "<影片路徑>" --json
```

⏱ **一支 100 秒的影片要 3-20 分鐘**（看有沒有 GPU）。
用背景執行，**不要設短逾時**。過程中會持續印進度。

## 回報結果

拿到 JSON 後，用白話告訴使用者：

> 剪好了。原長 97.8 秒 → 85.5 秒，剪掉 12.7%。
> 淨毛片、字幕（SRT + 校對檔）、以及一份「剪了哪些、為什麼」的對照表都在影片旁邊。

**主動提一句**：如果他覺得剪得不對，可以打開 `_剪輯判斷對照.txt` 逐刀看，
改 `_待剪清單.json` 之後用 `--apply` 重剪，不必重跑整個辨識（快很多）。

## 先複核再剪

使用者說「先給我看要剪哪些」時：

```bash
python cli.py cut "<影片>" --plan-only --json     # 只產清單，不剪
# 使用者複核、修改 _待剪清單.json 之後
python cli.py cut --apply "<清單.json>" --json    # 依修改後的清單剪
```

## 判讀輸出

| 檔案 | 給誰用 |
|---|---|
| `_淨毛片.mp4` | 成品 |
| `_字幕校對_V1.txt` | 給人讀與改（純文字、無時間碼） |
| `_字幕.srt` | 給剪輯軟體與平台 |
| `_剪輯判斷對照.txt` | 逐刀說明剪了什麼、為什麼 |
| `_待剪清單.json` | 可改後重剪 |
| `_暴走作廢.json` | 有的話代表某層提議被安全閥擋下，可複審 |

## 注意

- 出現「⚠ 找不到同名腳本」是**正常的**，沒腳本一樣能剪，只是校字沒有參考稿。
- 出現「保護名單擋下 N 段」代表系統阻止了誤剪 CTA 或開場鉤子，這是好事。
- 「判斷腦建議剪掉 0 段」不代表壞掉——很多片子在段落層級本來就沒有重複。
