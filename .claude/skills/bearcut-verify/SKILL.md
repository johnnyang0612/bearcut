# 檢查成片品質

## 執行

```bash
python cli.py verify "<成片>" --json           # 基本檢查
python cli.py verify "<成片>" --frames --json  # 順便抽接縫畫面
```

## 檢查什麼

| 類別 | 抓的問題 |
|---|---|
| 音畫字 | 成片長度與計畫對不上、字幕超出影片長度、沒有音軌、字幕起點太晚 |
| 字幕 | 簡體字殘留、英文黏字、跨段孤字、時間軸重疊 |
| 接縫畫面 | 每個刀口前後各抽一幀，看接得順不順、人物有沒有瞬移 |

## 怎麼回報

**不要照抄 JSON。** 用白話講，並區分嚴重度：

- **會影響觀看**（沒有音軌、字幕整份偏掉）→ 明確說「這個要修」
- **建議確認**（簡體字殘留、英文黏字）→ 說「可以重跑一次或手動改」
- **沒問題** → 就說檢查過了沒事，不要為了顯得認真而列一堆無關細節

加了 `--frames` 的話，告訴使用者圖在哪個資料夾、可以逐張翻。
**你自己也可以讀那些圖**來判斷接縫順不順——那正是它們存在的目的。

## 常見結果的意思

- 「偵測到 N 個簡體字」→ whisper 的中文辨識偶爾整片吐簡體，重跑通常就好
- 「有 N 段只有一兩個字」→ 可能句子被切斷，也可能是正常的短回應（對、好、嗯）
- 「字幕從 X 秒才開始」→ 前面可能有段落被漏掉，值得看一下

## 不要做

- 不要因為有警告就自作主張重跑剪輯——那會產出跟使用者剛看過的不一樣的片。
  先告訴他發現什麼，讓他決定。
